PROJECT HUB HERO: কম্প্যাক্ট ফাইল (ছবি ভেতরেই সংরক্ষিত)
=====================================================

ফাইল:
  hero-snippet.html  = আসল ফাইল। ১০টি কার্ড, ৫টি পোস্টার ছবি ও Dovashi লোগো ভেতরে বসানো। এটিই কপি করবেন।
  hub-hero.js        = একই কোড আলাদা JS ফাইল হিসেবে (একবার হোস্ট করে সব সাইটে লিংক দিতে চাইলে)।
  index.html         = টেস্ট পেজ। ব্রাউজারে খুলে দেখুন।

কীভাবে প্রতিটি সাইটে বসাবেন (পদ্ধতি ক, সবচেয়ে সহজ):
  1. সাইটের index.html ফাইল খুলুন।
  2. hero-snippet.html এর পুরো লেখা কপি করে <body> ট্যাগের ঠিক পরে বসান।
  3. ফাইল সেভ করে আবার আপলোড করুন:
     - Vercel: প্রজেক্ট ফোল্ডার আবার deploy করুন (GitHub থাকলে commit/push করলেই হয়)।
     - Netlify: Deploys পেজে নতুন ফোল্ডার ড্র্যাগ করে ছাড়ুন।
  4. Dovashi (PWA): sw.js এ CACHE = "dovashi-v3" কে "dovashi-v4" করে দিন, নইলে পুরোনো ক্যাশ দেখাতে পারে।

পদ্ধতি খ (একবার হোস্ট, সবখানে লিংক):
  hub-hero.js একটি সাইটে আপলোড করুন, বাকি সাইটে <body> এর পরে এটি বসান:
    <div id="project-hub-hero"></div>
    <script src="https://আপনার-সাইট/hub-hero.js" defer></script>
  (Dovashi এর অফলাইন মোডে বাইরের স্ক্রিপ্ট চলে না, তাই ওখানে পদ্ধতি ক ভালো।)

নতুন সাইট যোগ করা:
  A) হিরোর "যোগ করুন" বাটনে চাপুন: নাম, লিংক, লোগো দিন। এটি শুধু ওই ব্রাউজারে ও ওই সাইটে সংরক্ষিত থাকে।
  B) সব সাইটে স্থায়ীভাবে চাইলে ফাইলের ওপরের SITES তালিকায় একটি লাইন যোগ করুন:
     { id:'mysite', name:'MY SITE', url:'https://...', logo:'https://লোগোর-লিংক', photo:'', theme:'cyber' }
     এরপর আবার সব সাইটে বসান। হিরোর "কনফিগ কপি" বাটনও তালিকা বানিয়ে দেয়।

ছবির নিয়ম:
  logo  = কার্ডের মাঝের লোগো। খালি থাকলে সাইটের favicon, না পেলে প্রথম অক্ষর দেখায়।
  photo = কার্ডের পেছনের পোস্টার ছবি। 'img:abc' লিখলে ফাইলের ভেতরের ছবি, অথবা https:// লিংক।
  বর্তমান ছবি: amarboi=abc, zoni=cosmetics, dovashi=quran, airgds=baggage, gz=spices।
  Quran ছবি Dovashi তে ও spices ছবি Guangzhou Sourcing এ বসানো হয়েছে। ভুল হলে সংশ্লিষ্ট লাইনের photo: 'img:...' বদলে দিন।

রিফ্রেশে কার্ড থাকে: কার্ড কোডেই আছে, আর আপনার যোগ/এডিট ব্রাউজারে সংরক্ষিত থাকে।
লিংক নতুন ট্যাবে না খুলে একই ট্যাবে খুলতে: CONFIG এ openInNewTab: false করুন।
